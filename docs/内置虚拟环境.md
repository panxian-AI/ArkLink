# 内置虚拟环境：`arklink env`

> 目标：让「另开一台机器专门跑 QQ」变成一条命令。用户不需要打开 VirtualBox 界面，
> 不需要手装 Ubuntu，不需要记住 Xvfb / openbox / xdotool 的顺序。

## 一、它解决的问题

Windows 上发送消息必须把 QQ 顶成前台窗口——抢焦点、占剪贴板。根源是**同一个登录会话
只有一条输入队列**（详见 [Windows会话隔离.md](Windows会话隔离.md)）。把 QQ 放进一台
独立的虚拟机，输入就只进那台机器，宿主机上你在打的字一个都不会错。

但「独立虚拟机」传统上意味着：装 VirtualBox → 下载 2.6GB ISO → 建 VM → 装系统 →
装 QQ → 装中文字体 → 配虚拟屏幕 → 配开机自启。八步，每步都能卡住。

`arklink env` 把这八步收进四条命令，并且**每一步都能先看再做**。

## 二、一条命令全自动（推荐）

```bash
arklink env setup --download      # 下载/续传 ISO → 建 VM → 等装完 → 推代码装 QQ
```

`setup` 每一步都是幂等的：已经做过的自动跳过，中途断了（网络断、机器重启）
重跑同一条命令就接着来。跑完会直接打印**扫码页地址**和下一步。

<details>
<summary>分步命令（想一步步看的时候用）</summary>

```bash
arklink env plan                        # 算账：能不能装、装哪块盘、占多少（不动手）
arklink env create --download           # 建 VM + 无人值守装 Ubuntu + 无头启动
arklink env wait                        # 等系统装好（轮询 guestcontrol，10–20 分钟）
arklink env push --password <上一步给的>  # 把本仓库推进 guest，装 QQ/Xvfb/Arklink
arklink env status                      # 看状态、端口、磁盘真实占用
arklink env doctor                      # 体检：哪一环坏了、怎么修（可接 AI）
```

</details>

配上 `up` / `down` / `eject` / `destroy` 就是完整生命周期：

| 命令 | 作用 | 会不会动你的东西 |
|------|------|-----------------|
| `env setup` | 上面 create+wait+push 的自动化串联，幂等可重跑 | 会（首次要下载 ISO） |
| `env plan` | 只读探测：VBoxManage、各盘余量、内存，给出计划与结论 | 不会 |
| `env create` | 建 VM、建 8GB 动态盘、无人值守装系统、无头启动 | 会（需要 `--iso` 或 `--download`） |
| `env wait` | 等无人值守安装完成（guestcontrol 能进去就算好） | 不会 |
| `env push` | 通过 Guest Additions 把仓库拷进 guest 并跑 `tools/setup_guest.sh` | 只动 guest |
| `env doctor` | 宿主+guest 体检：规则表给原因与修复命令，`--apply` 直接修 | 只读；`--apply` 才动手 |
| `env up` / `down` | `startvm --type headless` / ACPI 关机 | 只动 VM |
| `env eject` | 摘掉安装盘、改回硬盘启动 | 只动 VM |
| `env destroy` | 注销 VM 并删虚拟磁盘 | **必须 `--yes`** |

### 扫码登录：在 WebUI 里自己看（不用别人给截图）

```bash
arklink env setup                       # 跑完打印 http://127.0.0.1:6800/screen
```

浏览器打开 `http://127.0.0.1:6800/screen` 就是**虚拟屏幕的实时画面**（2 秒刷新）：
扫码登录、看聊天窗口、看报错弹窗都在这张图上。主页右上角也有入口。

### 出问题：先体检，再让 AI 看

```bash
arklink env doctor                                   # 规则体检：命中哪条、原因、修复命令
arklink env doctor --apply                           # 直接执行修复命令
arklink env doctor --ai --key sk-xxxx                # 疑难杂症交给 DeepSeek（key 只存一次）
```

DeepSeek key 存在 `~/.arklink/ai.json`（0600），也可以用环境变量
`DEEPSEEK_API_KEY`。AI 只**建议**命令，`--apply` 才会真的执行。

`env plan` 的实测输出（本机，未装 VirtualBox 时）：

```
虚拟机名  arklink
磁盘位置  E:\arklink
虚拟磁盘  E:\arklink\arklink.vdi（上限 8GB，实际预期 3.4GB）

端口      WebUI 127.0.0.1:6800   SSH 127.0.0.1:2222
```

## 三、`create` 到底做了什么

`create --dry-run` 会把命令原样打出来（下面是本机实测）：

```
[1/7] 建虚拟机 …        VBoxManage createvm --name arklink --basefolder E:\arklink --ostype Ubuntu_64 --register
[2/7] 配置硬件/网络 …   VBoxManage modifyvm arklink --memory 2048 --cpus 2 --vram 16 --graphicscontroller vmsvga
                                            --audio-driver none --clipboard-mode disabled --draganddrop disabled
                                            --nic1 nat --boot1 dvd --boot2 disk --rtcuseutc on
[3/7] 建虚拟磁盘 …      VBoxManage createmedium disk --filename E:\arklink\arklink.vdi --size 8192 --format VDI
[4/7] 挂 SATA 控制器 …  VBoxManage storagectl arklink --name SATA --add sata --controller IntelAhci --portcount 2
[5/7] 挂硬盘 …          VBoxManage storageattach arklink --storagectl SATA --port 0 --device 0 --type hdd
[6/7] 端口映射 …        VBoxManage modifyvm arklink --natpf1 webui,tcp,127.0.0.1,6800,,6800
                                            --natpf1 ssh,tcp,127.0.0.1,2222,,22
[7/7] 无人值守安装 …    VBoxManage unattended install arklink --iso=<iso> --user=arklink --password=<随机>
                                            --install-additions --additions-iso=<VBoxGuestAdditions.iso>
                                            --post-install-command "echo 'arklink ALL=(ALL) NOPASSWD:ALL' > …"
```

几个刻意的选择：

* **`--basefolder` 换盘**：镜像落在余量最大的非系统盘，而不是 `C:\Users\...\VirtualBox VMs`。
  不靠改全局 `machinefolder`，避免影响你别的虚拟机；
* **`--clipboard-mode disabled` / `--draganddrop disabled`**：隔离的一部分。既然目标就是
  「别碰宿主剪贴板」，就不要留双向通道；
* **`--audio-driver none`**：纯文字收发用不到声卡，省一点；
* **端口只绑 `127.0.0.1`**：WebUI 和 SSH 都只能在宿主机本机访问。要远程就自己开隧道，
  默认不暴露；
* **无人值守而不是手动装**：`unattended install` 会自己生成 autoinstall 应答盘
  （VirtualBox 内置 mkisofs，Windows 上不需要额外工具），装完自动装增强包、自动开
  NOPASSWD sudo，`env push` 才能免密码推代码；
* **随机密码**：不给 `--password` 就生成一个，记在 `~/.arklink/env.json`（POSIX 下 0600）。

## 四、`push` 之后 guest 里发生了什么

`env push` 干两件事：`guestcontrol copyto` 把仓库拷到 `/opt/ArkLink`，然后
`guestcontrol run` 执行 `tools/setup_guest.sh --source /opt/ArkLink`。这个脚本负责：

1. 按发行版选对音频包（Ubuntu 24.04 是 `libasound2t64`，写错直接依赖失败）；
2. 装 Xvfb / openbox / xdotool / 中文字体（**字体缺了中文变方块，坐标也会全偏**）；
3. 用 `apt install ./QQ.deb` 装 QQ（不是 `dpkg -i`，让 apt 解依赖）；
4. 建 venv 装 Arklink，写 `/opt/arklink/start.sh` 和 systemd 服务；
5. 自检：找得到 QQ 窗口、WebUI 进程在跑。

第一次仍需扫码登录——QQ 没有无交互登录。用 VNC 一次即可：

```bash
apt-get install -y x11vnc && x11vnc -display :99 -nopw -forever &
```

扫完把 `~/.config/QQ` 备份，换机器直接拷。

## 五、资源账单

| 项 | 数值 | 说明 |
|---|---|---|
| 虚拟磁盘上限 | 8GB | 动态分配，只在写的时候长 |
| 实际占用 | ≈3.4GB | 系统 2.2 + QQ 0.6 + 依赖 0.45 + 用户数据 |
| 内存 | 2048MB | 宿主 15GB 时留 13GB |
| CPU | 2 核 | QQ + Xvfb + WebUI 够用 |
| 宿主系统盘 | 只多 VirtualBox 本体 ~300MB | 镜像全部在 `--basefolder` 指的盘上 |

`create` 结束后跑 `env status`，`disk_used_gb` 是**虚拟盘文件的真实大小**，不是 8GB。

## 六、为什么只做了 VirtualBox

| 形态 | 现状 | 原因 |
|------|------|------|
| VirtualBox | ✅ `arklink env` | 跨平台（Win/Linux/macOS）、无需开 Hyper-V、支持无人值守、有 Guest Additions 可推文件 |
| WSL2 | ❌ 未实现 | 要开 `VirtualMachinePlatform` 并重启；WSLg 会把窗口画到宿主桌面，必须绕开；只在 Windows 上有 |
| Windows 独立会话 | ❌ 未实现 | 不需要虚拟化，但要求另一账户登录过一次，重启后还要再登；跨会话搬运代码没有现成通道 |
| Hyper-V | ❌ 未实现 | Windows 家庭版没有；开起来会和 VirtualBox/VMware 冲突 |

这三条不是否定，是**没做**。`arklink env` 的探测层（`probe.py`）与计划层（`plan.py`）
是独立于 VirtualBox 的，加一个后端只要实现同名的 create/start/stop/status 即可。

## 七、常见卡点

| 现象 | 原因 | 处理 |
|------|------|------|
| `找不到 VBoxManage` | 没装或不在 PATH | 装 VirtualBox 7.x；Linux 上 `apt install virtualbox` |
| `ISO 校验失败` | 下载不完整或镜像被换 | 删 `.part` 重下；校验和取自官方 `SHA256SUMS` |
| 装完又进安装程序 | 没摘 ISO | `arklink env eject` |
| `env push` 报 guestcontrol 错 | 缺增强包 | 重装时带上 `--install-additions`；或手动挂 `VBoxGuestAdditions.iso` |
| WebUI 打不开 | guest 里服务没起 / 端口没映射 | `env status` 看 `state`；SSH 进去 `systemctl status arklink` |
| 中文全是方块 | 没装 CJK 字体 | `apt install fonts-wqy-microhei`，然后重启 QQ |
| 磁盘涨到 8GB | QQ 缓存 | QQ 设置里限缓存 500MB，清 `~/.config/QQ/nt_data/{Pic,File,Video}` |

## 八、安全边界

* VM 与宿主之间**只有 NAT 端口映射**，且都绑 `127.0.0.1`；
* 剪贴板与拖放默认关闭，不存在「宿主复制、guest 粘贴」的通道；
* `~/.arklink/env.json` 里存了 guest 密码（本地一次性虚拟机的密码），POSIX 下 0600；
  Windows 上依赖用户目录 ACL；
* `destroy` 必须显式 `--yes`，因为它会连虚拟磁盘一起删——没有回收站。
