# 自己用：不用开发者，也不用记参数

这份文档只讲一件事：**拿到这台电脑，你怎么自己把它跑起来、自己改白名单、自己发消息。**
不涉及协议逆向，不涉及改代码。

---

## 一、最短路径（三分钟）

Windows：双击仓库根目录的 **`start.bat`**。

第一次双击做的事（约 1–2 分钟，需要联网）：

1. 建一个 `.venv` 虚拟环境（不污染系统 Python）
2. `pip install -e .` 装依赖
3. 起控制台，并自动打开浏览器

第二次以后双击，只做第 3 步，两三秒就出来。

Linux / macOS：`./start.sh`。它还会自己判断引擎——有 `xdotool` + `DISPLAY`
就用 `x11`（无头 X 里点 QQ），否则用 `host`（Windows 那种窗口通道）。

**关掉那个黑窗口 = 停止服务。** 想让它一直在，见第六节。

---

## 二、控制台里有什么

打开后是 `http://127.0.0.1:6800/`，一页看全：

| 区块 | 作用 |
|---|---|
| 引擎 / 可用性 | 当前用哪个通道发；不可用时直接写原因（QQ 没开、缺 xdotool…） |
| 策略 | 现在允许哪个号、发给谁、群聊开没开 |
| 发送 | 填收件人 + 内容；收件人支持多个（逗号分隔），内容支持多行（一行一条） |
| 记录 | 每一条的结果、时间、失败码 |
| 日志 | 最近的运行日志，出问题先看这里 |
| 体检 | 环境自检 |

**所有发送默认只在你点「发送」时才真发。** 想先演练，命令行加 `--yes` 之外的默认行为就是 dry-run。

## 三、改白名单（不用改代码）

白名单存在 `~/.arklink/policy.json`（Windows 是 `C:\Users\<你>\.arklink\policy.json`）。
你不用手写它，用三条命令：

```bash
arklink peers                              # 看现在允许谁
arklink peers allow 示例好友                    # 加一个人（备注名）
arklink peers allow 505 --group            # 加一个群：同时打开群聊开关
arklink peers deny 505                     # 移除
arklink peers reset --yes                  # 恢复默认：只发示例好友、群聊关闭
```

改完**立刻生效**（下一次发送就按新策略；控制台刷新页面即可）。

文件长这样，看得懂就能手改：

```json
{
  "version": 1,
  "allowed_uins": ["1000000001"],
  "allowed_peers": ["示例好友", "505"],
  "allow_group": true,
  "allowed_groups": ["505"],
  "max_length": 3000
}
```

两条硬规则：

- **拼错的键名会被忽略**，不会因为写错一个字母而把闸门放开；
- **文件坏了（不是合法 JSON）等于没写**，自动退回默认值（只发示例好友）。

### 名字从哪来

控制台搜索框认的是**备注/昵称/群名**，不是 `u_xxx` 内部 uid。所以白名单里直接写
你眼睛在 QQ 里看到的名字就行，例如 `示例好友`、`505`。

如果名字重名（两个「小王」），策略会拒绝并告诉你「匹配到多个对象」，此时改用 QQ 号。

## 四、给 505 群发测试消息（完整三步）

```bash
# 1. 开白名单：505 当成群，同时打开群聊开关
arklink peers allow 505 --group

# 2. 演练：不真发，只验证「策略放行 + 能搜到这个群」
arklink send --to 505 --text "群通道自检"

# 3. 真发
arklink send --to 505 --text "群通道自检" --yes
```

第 2 步输出 `[OK ] dry-run` 说明策略和解析都通过了；要看到 `[FAIL]` 就把
`code=` 和提示读一遍——`1403` 是策略拒绝，`1404` 是引擎不支持或找不到对象。

控制台里做同样的事：收件人填 `505`，内容填一行，点发送。

> 群聊默认是**关**的。这是刻意的：群发一次影响几十上百人，必须由你显式打开一次，
> 而不是某次误操作就发出去。

## 五、不打开浏览器，纯命令行

```bash
arklink send --to 示例好友 --text "到公司了" --yes
arklink send --to 示例好友,505 --text "多对象用逗号" --yes      # 多个对象
arklink send --to 示例好友 --text $'第一条\n第二条' --yes        # 多条按行拆
arklink send --to 示例好友 --text "只演练"                      # 不加 --yes = 不发
arklink send --to 示例好友 --text "看 JSON" --json
```

发给多个人是**顺序执行、结果一一对应**：中间某条失败，后面的照常发，返回列表里
每条都有自己的 `ok`。

## 六、让它一直在后台跑（不用每次双击）

Windows，两种做法：

1. **开机自启**：`Win+R` → `shell:startup` → 把 `start.bat` 的**快捷方式**拖进去。
   开机后它会自己起控制台，浏览器也会自己弹一下（不想要就右键快捷方式 → 属性 →
   目标末尾加 ` --no-browser`）。
2. **只起服务不开窗口**：在快捷方式目标末尾加 ` --no-browser`，窗口最小化即可；
   窗口一关服务就停，所以别点关闭。

Linux（systemd）：

```ini
# /etc/systemd/system/arklink.service
[Unit]
Description=ArkLink console
After=network.target

[Service]
WorkingDirectory=/opt/ArkLink
ExecStart=/opt/ArkLink/.venv/bin/python -m arklink start --engine x11 --no-browser
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now arklink
```

## 七、想让手机 / 另一台电脑也能看

默认只听 `127.0.0.1`，别人访问不到——这是安全默认值，别随手改。

真要远程：

```bash
arklink start --host 0.0.0.0 --password 你自己想的口令
```

**必须带 `--password`**。不带也起得来，但控制台会红字警告：任何能连上这个端口的人
都能用你的 QQ 发消息。更稳的做法是用 SSH 隧道或 Tailscale，不要把端口直接开到公网。

## 八、出问题按这个顺序查

| 现象 | 先看 | 处理 |
|---|---|---|
| 控制台打不开 | 黑窗口里有没有报错 | 端口被占：`arklink start --port 6801` |
| 引擎显示不可用 | 上方提示的原因 | Windows 要 QQ 已登录；Linux 要 `xdotool` + `DISPLAY` |
| 发送返回 1403 | 提示里的账号/收件人 | 换号了要改 `allowed_uins`；收件人不在白名单就 `peers allow` |
| 发送返回 1404 | 提示原文 | 「没有这个对象」→ 名字写错，或先 `arklink peers allow 名字` |
| 改了白名单没生效 | `arklink peers` 的输出 | 确认改的是同一个 `policy.json`（`ARKLINK_POLICY` 可切文件） |
| 中文变方块 / 点不中 | 只有 Linux 无头环境才有的问题 | 见 [无头Linux运行.md](无头Linux运行.md) 的字体一节 |
| 认不出当前是哪个号 | 策略提示「拒绝盲发」 | 同机多开时按内存指纹认号，认不出就提示；关掉另一个号再试 |

**一键体检**：`arklink doctor`。它把环境、模块、进程、管道、服务端、配置挨个查一遍。

## 九、卸载 / 回到干净状态

```bash
arklink peers reset --yes      # 恢复默认白名单
rm -rf ~/.arklink              # 策略、历史、状态（Windows 是 %USERPROFILE%\.arklink）
rm -rf .venv                   # 虚拟环境
```

仓库本身删掉就没了，不写注册表、不装服务、不改系统设置。

## 十、边界（写在这里，免得以后自己踩）

- 默认**只允许 1000000001 发**。换成别的号要改 `policy.json` 的 `allowed_uins`，
  这是刻意留的一道坎：账号错了，发出去的话就收不回来了。
- 默认**只允许示例好友**。加人用 `peers allow`，一次一个，改完自己复核 `arklink peers`。
- **群聊默认关**。打开需要 `--group`，且会记进 `allowed_groups`。
- 所有发送都有记录（控制台「记录」页），出事能倒查。
